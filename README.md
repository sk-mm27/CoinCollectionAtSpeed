## **Игровой процесс:**
Передвижение осуществляется на стрелки. 
Управляя синим квадратом собирайте золотые монеты.
Каждая собранная монета увеличивает таймер. 
После 10 собранных монет на поле появляются новые.
Игра завершается по истечению таймера.

## **Цель игры:**
Собрать как можно больше монет до конца таймера.
